## 📌 Project Overview
Analyzed 1000 Amazon-style e-commerce orders to uncover sales trends, customer behavior, and top-performing products using Microsoft Excel.

## 🔍 Key Insights
- **Central Region** has highest number of orders
- **UPI** is the most preferred payment method (21%)
- **Top Selling Products:** Sunglasses, Wireless Headphones, Wall Clock
- **Low Selling:** Jeans & Kurta
- Total Orders Analyzed: 1000+

## 🛠️ Tools Used
- MS Excel
- Pivot Tables
- Bar Chart, Pie Chart, Donut Chart
- Data Cleaning & Sorting
